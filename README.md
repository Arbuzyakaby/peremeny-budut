# Перемены будут

**Змея против Гигантской Яичницы** — аркада на Godot 4.7. Змея пожирает плюшевых медведей,
ломает ржавые вилки, глотает прыгающие таблетки, перенимает приёмы врагов и сражается
с гигантской яичницей. Но всё не то, чем кажется.

Вся графика и весь звук генерируются кодом: в проекте нет ни одной картинки или аудиофайла.
Текстуры — процедурные шейдеры, звуки и музыка синтезируются при запуске.

## Скачать

Готовая сборка для Windows — на странице [Releases](../../releases/latest):
скачай `PeremenyBudut.exe` и запусти. Установка не нужна.

> Windows может предупредить, что приложение от неизвестного издателя (файл не подписан).
> Нажми «Подробнее» → «Выполнить в любом случае».

## Управление

| Клавиша | Действие |
|---|---|
| ← → / A D / мышь | Поворот |
| Shift | Спринт (тратит стамину) |
| Пробел / ЛКМ / F | Атака съеденного медведя |
| 1 / 2 / 3 | Выбор улучшения между этапами |
| Esc / P | Пауза |
| M | Звук вкл/выкл |

## Что внутри (v5.0)

- **Четыре этапа:**
  1. **Медведи** — съешь нужное число плюшевых медведей.
  2. **Ржавые вилки** — спринтуют на змею. Атаковать в лоб нельзя: зубцы! Заходи сбоку или сзади,
     а вилка, врезавшаяся в бортик, застревает — лучший момент.
  3. **Прыгающие таблетки** — прыгают на змею и давят её, а при приземлении поднимают ударную волну,
     которая оглушает. Есть таблетки можно, только пока они на земле.
  4. **Гигантская Яичница** — три фазы, шесть атак. На помощь ей приходят медведи, вилки и таблетки.
     Кусай открытый желток! Вилку в спринте можно направить прямо в яичницу.
- **Восемь видов медведей:** обычные, боксёры, метатели пуговиц, каратисты, швеи с иглами,
  **ниндзя** (исчезают в дыму и мечут сюрикены), **хлопушки** (бросают хлопушки с фитилём)
  и **медсёстры** (накрывают других медведей щитом-пузырём).
- **Атаки медведей:** съев особого медведя, змея получает его приём — пуговицы, веер игл, удар с разбега,
  вертушку, теневой рывок, хлопушку или заплатку (+1 жизнь).
- **Древо навыков:** за каждый забег змея получает чешуйки и тратит их в меню на три ветки —
  Тело, Манёвр, Атака (12 навыков с рангами). Между этапами — выбор одного из трёх улучшений.
- **Четыре сложности** — от лёгкой до **Ультра-Хардкора**: 1 жизнь, навыки и улучшения отключены,
  враги быстрее и злее, очки ×5.
- **Френдли фаер:** враги попадают друг в друга — медведей можно стравить.
- **Расширенный финал:** протокол эксперимента с результатами забега, полки с образцами прошлых
  экспериментов, выбор, который ничего не меняет, огнетушитель, штамп — и кое-что в пепле.
- **Звук:** синтезатор со сглаженными волнами, фильтрами и ограничителем; отдельная петля треска огня.
- **Настройки:** громкость музыки и эффектов, тряска экрана, управление мышью, FPS, полный экран, V-Sync.

## Запуск из исходников

1. Установи [Godot 4.7](https://godotengine.org/download).
2. Открой в Godot файл `project.godot` и нажми **F5**.

Чтобы собрать `.exe` самому: **Проект → Экспорт → Windows Desktop** (нужны шаблоны экспорта 4.7.2).

Отладочные аргументы (после `--`): `--stage=0..3`, `--diff=0..3`, `--autopilot`, `--ending`,
`--skills`, `--perks`, `--dump-sfx`. Отладочные забеги не сохраняют рекорды и чешуйки.

## Структура

| Файл | Что делает |
|---|---|
| `scripts/game.gd` | Этапы, сложность, спавн, столкновения, атаки змеи, улучшения |
| `scripts/snake.gd` | Змея: движение, спринт, стамина, рывок, оглушение, щит |
| `scripts/teddy_bear.gd` | Медведи всех восьми видов и их поведение |
| `scripts/fork.gd`, `pill.gd` | Ржавые вилки и прыгающие таблетки |
| `scripts/fried_egg_boss.gd` | Босс — гигантская яичница |
| `scripts/skills.gd`, `skill_tree_ui.gd` | Древо навыков, чешуйки, улучшения забега |
| `scripts/tex.gd` | Процедурные текстуры: шейдеры пола и материалов, мягкие спрайты |
| `scripts/hud.gd` | Интерфейс: меню, настройки, панели, древо навыков, субтитры, титры |
| `scripts/ending.gd`, `lab.gd`, `fire.gd` | Финальная катсцена |
| `scripts/synth.gd`, `sfx.gd` | Синтез звуков и музыки, проигрывание |
| `scripts/settings.gd` | Сохранение настроек |
