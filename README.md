# Перемены будут

**Змея против Гигантской Яичницы** — аркада на Godot 4.7. Змея пожирает плюшевых медведей,
перенимает их приёмы и сражается с гигантской яичницей. Но всё не то, чем кажется.

Вся графика и весь звук генерируются кодом: в проекте нет ни одной картинки или аудиофайла.

## Скачать

Готовая сборка для Windows — на странице [Releases](../../releases/latest):
скачай `PeremenyBudut.exe` и запусти. Установка не нужна.

> Windows может предупредить, что приложение от неизвестного издателя (файл не подписан).
> Нажми «Подробнее» → «Выполнить в любом случае».

## Управление

| Клавиша | Действие |
|---|---|
| ← → / A D / мышь | Поворот |
| Shift | Спринт (тратит стамину) |
| Пробел / ЛКМ / F | Атака съеденного медведя |
| Esc / P | Пауза |
| M | Звук вкл/выкл |

## Что внутри

- **Три сложности** — от 5 жизней и 10 медведей до 2 жизней и 20 медведей.
- **Пять видов медведей:** обычные, боксёры, метатели пуговиц, каратисты (бьют ногой в прыжке)
  и швеи (метают иголки с пуговицами, которые пришивают змею).
- **Френдли фаер:** медведи попадают друг в друга и начинают мстить — их можно стравить.
- **Атаки медведей:** съев особого медведя, змея получает его приём — пуговицы, веер игл,
  удар с разбега или вертушку. Ими можно ранить и яичницу.
- **Стамина и спринт.** Выдохлась — ползёт медленнее, пока не отдышится.
- **Босс — Гигантская Яичница** с тремя фазами и шестью видами атак. Кусай открытый желток!
- **Финал** с выбором, который ничего не меняет.
- **Настройки:** громкость музыки и эффектов, тряска экрана, управление мышью, FPS, полный экран, V-Sync.

## Запуск из исходников

1. Установи [Godot 4.7](https://godotengine.org/download).
2. Открой в Godot файл `project.godot` и нажми **F5**.

Чтобы собрать `.exe` самому: **Проект → Экспорт → Windows Desktop** (нужны шаблоны экспорта 4.7.2).

## Структура

| Файл | Что делает |
|---|---|
| `scripts/game.gd` | Состояния игры, сложность, спавн, столкновения, атаки змеи |
| `scripts/snake.gd` | Змея: движение, спринт, стамина, рывок |
| `scripts/teddy_bear.gd` | Медведи всех видов и их поведение |
| `scripts/fried_egg_boss.gd` | Босс — гигантская яичница |
| `scripts/hud.gd` | Интерфейс: меню, настройки, панели, субтитры |
| `scripts/ending.gd`, `lab.gd`, `fire.gd` | Финальная катсцена |
| `scripts/synth.gd`, `sfx.gd` | Синтез звуков и музыки |
| `scripts/settings.gd` | Сохранение настроек |
