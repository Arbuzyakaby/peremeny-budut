# Перемены будут

**Змея против Гигантской Яичницы** — аркада на Godot 4.7 для Windows и Android.

Змея пожирает плюшевых медведей, ломает ржавые вилки, глотает прыгающие таблетки, перенимает приёмы врагов
и сражается с гигантской яичницей. Но всё не то, чем кажется.

Вся графика и весь звук генерируются кодом: в проекте нет ни одной картинки, аудиофайла или шрифта.

## Скачать

На странице [Releases](../../releases/latest):

- **Windows** — `PeremenyBudut.exe`. Установка не нужна, просто запусти.
  > Windows может предупредить о неизвестном издателе (файл не подписан): «Подробнее» → «Выполнить в любом случае».
- **Android** — `PeremenyBudut.apk`, нужен Android 7.0 и новее.
  > Открой файл на телефоне и разреши установку из этого источника. Игра идёт в горизонтальной ориентации.

## Управление

| ПК | Телефон | Действие |
|---|---|---|
| ← → / A D / мышь | джойстик в левой половине экрана | поворот |
| Shift | кнопка ⚡ или стик до упора | спринт (тратит стамину) |
| Пробел / ЛКМ / F | кнопка АТАКА или двойной тап | атака съеденного медведя |
| 1 / 2 / 3 | тап по карточке | выбор улучшения между этапами |
| Esc / P | кнопка паузы / «Назад» | пауза |
| M | — | звук вкл/выкл |
| F1 / \` | кнопка `</>` | панель разработчика |

В настройках можно выбрать схему «палец ведёт змею», плавающий или фиксированный стик, размер
и прозрачность кнопок и раскладку для левши.

## Что внутри (v6.0)

- **Четыре этапа:**
  1. **Медведи.**
  2. **Ржавые вилки.** Бить только сбоку или сзади.
  3. **Прыгающие таблетки.** Давят и оглушают ударной волной.
  4. **Гигантская Яичница.** Ей помогают все враги.
- **Восемь видов медведей.** Каждый особый медведь даёт змее свою атаку.
- **Древо навыков** за чешуйки и **улучшения** между этапами.
- **Четыре сложности**, включая Ультра-Хардкор.
- **Расширенный финал** с протоколом эксперимента и выбором, который ничего не меняет.
- **Мобильная версия:**
  - сенсорное управление с мультитачем;
  - безопасная зона выреза камеры, широкие экраны 20:9;
  - вибрация, пауза при сворачивании, системная кнопка «Назад»;
  - рендерер Compatibility, звук синтезируется в фоне с экраном загрузки.
- **Настройки:** 35 параметров на пяти вкладках — Звук, Экран, Игра, Управление, Доступность
  (режим для дальтоников, контрастные предупреждения, меньше анимации и др.).
- **Дизайн-язык «Ящик экспериментов»** — см. [docs/DESIGN.md](docs/DESIGN.md).
- **Панель разработчика:**
  - FPS и график кадров, читы, прыжок по этапам, спавн любых врагов, скорость времени;
  - хитбоксы, превью звуков, витрина UI-кита, запуск тестов прямо в игре.
  - На телефоне включается 7 нажатиями на номер версии в настройках. Любой чит помечает забег
    как отладочный: рекорды и чешуйки не сохраняются.

## Запуск из исходников

1. Установи [Godot 4.7](https://godotengine.org/download).
2. Открой `project.godot` и нажми **F5**.

Сборка: **Проект → Экспорт** — пресеты «Windows Desktop» и «Android». Для Android нужны JDK 17,
Android SDK и шаблоны экспорта 4.7.2.

Отладочные аргументы (после `--`):

| Аргумент | Что делает |
|---|---|
| `--stage=0..3` | начать сразу с этапа |
| `--diff=0..3` | сложность |
| `--autopilot` | змея играет сама |
| `--ending` | сразу финал |
| `--touch` | мобильный режим на ПК, мышь работает как палец |
| `--dev` | открыть панель разработчика |
| `--open=pause\|end\|win\|perks\|skills\|settings` | открыть экран |
| `--shots=30,90` | сохранить скриншоты этих кадров в `user://shots` |
| `--dump-sfx` | выгрузить все звуки в WAV |

Отладочные забеги ничего не сохраняют.

## Автотесты

Своя лёгкая система тестов без аддонов: 85 тестов, около 760 проверок. Юнит-тесты покрывают
баланс, навыки, бой, настройки, сохранения, звук, змею и врагов. Интеграционные тесты проходят
весь забег, финал, экраны, тач-управление и панель разработчика.

```bash
godot --headless --path . -s res://tests/run_tests.gd
```

`-- --only=skills` — фильтр по имени, `-- --unit` — только юнит-тесты. Тесты пишут
во временную папку и не трогают настоящие сохранения. На GitHub они запускаются автоматически
при каждом пуше (`.github/workflows/tests.yml`).

## Структура

| Папка | Что внутри |
|---|---|
| `scripts/core/` | баланс, настройки (схема), сохранения, навыки, боевые расчёты, платформа, управление |
| `scripts/game/` | `game.gd` — состояния и этапы; враги, снаряды, атаки змеи, бой с боссом, демо меню, арена, эффекты, итоги |
| `scripts/entities/` | змея, медведи (внешний вид / поведение), вилки, таблетки, яичница, снаряды, волны |
| `scripts/ui/` | дизайн-язык, иконки, HUD, субтитры, тач-управление, панель разработчика, экраны и виджеты |
| `scripts/audio/` | синтез звуков и музыки, проигрывание |
| `scripts/ending/` | финал: сцены, лаборатория, пожар, яйцо, титры |
| `scripts/gfx/` | процедурные шейдеры и текстуры |
| `tests/` | раннер, юнит- и интеграционные тесты |
| `docs/` | дизайн-язык |
