# Архитектура

Как устроен код «Змеи против Гигантской Яичницы». Проект на Godot 4.7, всё на GDScript,
без аддонов, картинок, звуковых файлов и шрифтов: графика, звук и интерфейс строятся кодом.

## Сцена и точка входа

В проекте одна сцена — [`scenes/main.tscn`](../scenes/main.tscn), корневой `Node2D` со скриптом
[`scripts/game/game.gd`](../scripts/game/game.gd). Всё остальное создаётся из кода в `_ready()`.

`game.gd` — только диспетчер: состояния забега, этапы, счёт, итоги. Работу он раздаёт помощникам:

| Помощник | Файл | Отвечает за |
|---|---|---|
| `EnemyDirector` | `game/enemy_director.gd` | появление и обновление врагов по этапам, наборы матрёшек |
| `Squad` | `game/squad.gd` | кооперативный ИИ: роли, такты, клещи (см. [AI.md](AI.md)) |
| `Projectiles` | `game/projectiles.gd` | снаряды, ударные волны, промахи |
| `Abilities` | `game/abilities.gd` | атаки змеи, перенятые у медведей |
| `BossFight` | `game/boss_fight.gd` | бой с яичницей, фазы, открытый желток |
| `Arena` | `game/arena.gd` | ящик и его стенки на каждом этапе |
| `Fx` | `game/fx.gd` | частицы, всплывающие очки, вспышки |
| `MenuDemo` | `game/menu_demo.gd` | живой фон главного меню |
| `Replay` | `game/replay.gd` | запись последних 3 секунд для повтора гибели |
| `Hud` | `ui/hud.gd` | весь интерфейс, стек экранов, масштаб и безопасная зона |
| `Ending` | `ending/ending.gd` | финал: лаборатория, выбор, пожар, титры |

## Состояния

```
LOADING → MENU → LEVEL ⇄ PERK → … → BOSS_INTRO → BOSS → OUTRO → CUTSCENE → WIN
                   └────────────────────────────────────────────→ GAME_OVER
```

`State` в `game.gd`. Пауза — отдельный флаг дерева (`get_tree().paused`); HUD и панель разработчика
работают в `PROCESS_MODE_ALWAYS`, поэтому отвечают и на паузе.

## Слои интерфейса

`Hud` — `CanvasLayer` (слой 10). Внутри, снизу вверх:

1. `HudOverlay` — табло поверх поля (очки, жизни, стамина, босс). **Без масштаба интерфейса**,
   прижат к краям с учётом выреза камеры.
2. `TouchControls` — стик и аркадные кнопки.
3. `root` — масштабируемый слой (`Settings.ui_scale()`, 80–130%): субтитры и экраны меню.
   Экраны — наследники [`ui/screens/screen.gd`](../scripts/ui/screens/screen.gd), открываются стеком:
   «Назад» и Esc возвращают на предыдущий.
4. `DevPanel` — панель разработчика, всегда сверху.

Все цвета, размеры, шрифты и анимации интерфейса — только через
[`ui/design.gd`](../scripts/ui/design.gd), правила — в [DESIGN.md](DESIGN.md).

## Данные и сохранения

| Модуль | Что хранит | Где |
|---|---|---|
| `core/settings.gd` | настройки по схеме `SCHEMA` (см. [SETTINGS.md](SETTINGS.md)) | `user://settings.cfg` |
| `core/save_data.gd` | рекорды, чешуйки, открытые навыки (файл зашифрован, запись атомарная) | `user://save.dat` |
| `core/bestiary.gd` | открытые карточки картотеки | в сохранении |
| `core/daily.gd` | испытание дня и его рекорд | в сохранении |
| `core/balance.gd` | этапы, сложности, числа баланса | константы |
| `core/skills.gd` | древо навыков и улучшения между этапами | константы + сохранение |
| `core/tips.gd` | советы меню, загрузки, первых встреч и гибели | константы |
| `core/secrets.gd` | найденные пасхалки (v9.0) | в сохранении |

Значения настроек и кэши звуков, шрифтов и текстур живут в `static`-переменных: они переживают
перезагрузку сцены (новый забег), а при выходе освобождаются в `Game._on_quit()`.

Отладочные забеги (читы, `--stage`, `--autopilot`, `--ending`) ничего не сохраняют.

## Процедурные ресурсы

- **Графика** — `draw_*` в `_draw()` сущностей и виджетов, шейдеры и текстуры шума в `gfx/`.
- **Звук** — синтезатор в фоновом потоке, см. [AUDIO.md](AUDIO.md).
- **Пожар** — сеточная симуляция и шейдер, см. [FIRE.md](FIRE.md).
- **Шрифты** — системные (`SystemFont`) с запасными: Segoe UI на Windows, Roboto на Android.

## Платформы

[`core/platform.gd`](../scripts/core/platform.gd) определяет телефон, сенсорный экран, безопасную зону
и headless-режим тестов. На телефоне: рендерер Compatibility, более грубая сетка пожара без марева,
вибрация, пауза при сворачивании, системная «Назад» = Esc.

## Соглашения

- Комментарии и строки интерфейса — по-русски.
- Отступы — табы (`.editorconfig`).
- `preload` констант в начале файла; классы без `class_name`, чтобы не засорять глобальное пространство.
- Новая механика — вместе с тестом (см. [TESTING.md](TESTING.md)).
