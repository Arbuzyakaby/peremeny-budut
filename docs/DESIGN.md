# Дизайн-язык «Ящик экспериментов»

Правила, по которым сделан интерфейс «Змеи против Гигантской Яичницы» начиная с v6.0.
Все значения живут в коде, в [`scripts/ui/design.gd`](../scripts/ui/design.gd). В UI-файлах цвета,
размеры и шрифты напрямую не задаются, только через этот модуль. Вживую всё можно посмотреть
в панели разработчика (F1), на вкладке **UI-КИТ**.

## Идея

Игра — эксперимент учёного-бюрократа. Змея живёт в деревянном ящике на его столе, враги —
игрушки и предметы из лаборатории. Интерфейс продолжает эту историю. Он должен ощущаться как
дорогая игрушечная мастерская в лаборатории, а не как стандартный геймерский UI.

Цель — чтобы интерфейс выглядел современно и дорого, но оставался в стилистике игры:

- **Тёплое тёмное дерево** — все поверхности. Чистого чёрного и холодного серого нет.
- **Кремовая бумага протокола** — основной цвет текста.
- **Золото желтка** — единственный главный акцент: фокус, выбор, главное действие.
- **Сдержанность.** Один акцент на экран, много воздуха, мягкие тени вместо рамок-«коробок».
- **Игрушечность в деталях.** Пружинящие нажатия, круглые тумблеры, иконки-игрушки.
  Геометрия при этом строгая.

## Цвета

| Токен | Значение | Где |
|---|---|---|
| `SURFACE_0` | `#100A06` | подложка, затемнение, дорожки ползунков |
| `SURFACE_1` | `#1D130C` 95% | панели и экраны |
| `SURFACE_2` | `#2A1C12` | карточки, обычные кнопки |
| `SURFACE_3` | `#3A2719` | наведение |
| `LINE` / `LINE_STRONG` | `#5A3F27` / `#8A6440` | тонкие рамки / рамки активного |
| `INK` | `#140A05` | обводка текста над полем, текст на золоте |
| `CREAM` | `#FFF3DF` | основной текст |
| `MUTED` / `FAINT` | `#CDBA9E` / `#8C7A63` | вторичный текст / подписи и неактивное |
| `YOLK` / `YOLK_DEEP` | `#FFC93C` / `#E59A12` | главный акцент, фокус, выбранное |
| `MINT` | `#7BE08A` | успех, лечение, стамина |
| `TOMATO` | `#FF5A45` | опасность, урон, необратимые действия |
| `STEEL` | `#7FB8FF` | информация, оглушение, щит |
| `PLUM` | `#D46BFF` | Ультра-Хардкор, режим разработчика |

**Акценты этапов** (полоса цели, иконки): фанера `#D9A066` → ржавчина `#C0652C` →
аптечная бирюза `#5FD4C4` → чугун с золотом `#FFC93C`.

**Доступность.** Цвета предупреждений берутся функциями `danger()`, `warn()`, `safe()`.
Режим для дальтоников заменяет красный на оранжевый, а мятный — на синий. Высокая контрастность
делает линии предупреждений (`telegraph_width`) в 1.8 раза толще и увеличивает «!» над медведями.

## Типографика

Системные шрифты с цепочкой запасных: Segoe UI на Windows, Roboto на Android. Файлов шрифтов
в проекте нет, как нет и картинок.

| Роль | Размер | Вес | Применение |
|---|---|---|---|
| `display` | 72 | Black | заголовок итогов |
| `h1` | 44 | Black | заголовки экранов |
| `h2` | 30 | Black | подзаголовки |
| `h3` | 22 | Semibold | названия карточек, значения |
| `body` | 20 | Regular 600 | строки настроек |
| `small` | 16 | Regular 600 | описания |
| `caption` | 14 | Semibold | подписи, версии |
| `overline` | 13 | Black, капс | надписи над группами |
| `hud`, `hud_big`, `banner` | 18 / 34 / 44 | Black + обводка `INK` | всё, что поверх игрового поля |
| `mono` | — | Cascadia / Roboto Mono | цифры панели разработчика |

Заголовки `display` и `h1` получают мягкую тень-тиснение. Текст над игровым полем всегда
с обводкой, текст в панелях — без неё.

## Пространство и форма

- **Отступы** — шкала `4 · 8 · 12 · 16 · 24 · 32 · 48` (`SPACE[1..7]`). Других отступов нет.
- **Радиусы:** 8 (мелочь), 14 (кнопки, карточки), 22 (панели), «таблетка» (тумблеры,
  сегменты, бейджи).
- **Рамки** — 2 px. Цвет рамки говорит о состоянии: `LINE` в покое, `YOLK` в фокусе, цвет
  смысла у особых карточек.
- **Высота** — три уровня тени (`elevated(level)`): 1 — карточка, 2 — панель, 3 — диалог
  или панель разработчика.
- **Касания:** всё, что нажимается, не ниже 52 px (≈48 dp). Это правило действует и на ПК.

## Движение

| Токен | Длительность | Где |
|---|---|---|
| `FAST` | 120 мс | нажатие, наведение |
| `BASE` | 200 мс | появление элементов, тумблер |
| `SLOW` | 350 мс | панели и экраны |
| `SCENIC` | 600 мс | заголовки, сцены |

Появление — прозрачность плюс подъём на 14 px, easing *out-cubic*. Нажатие — пружина
(scale 0.95 → 1, *back*). Элементы списков появляются с задержкой 40 мс друг за другом.
Настройка **«Меньше анимации»** отключает смещения, масштаб и покачивания, оставляя только
прозрачность.

## Компоненты

| Компонент | Код | Правила |
|---|---|---|
| Кнопка | `Design.button(text, cb, variant)` | `Primary` (золото) — одна на экран; обычная; `Ghost` — второстепенное; `Danger` — необратимое, всегда с подтверждением повторным нажатием |
| Панель / экран | `ui/screens/screen.gd` | панель по центру, прокрутка, если не влезает; затемнение фона 62% |
| Карточка | `elevated(..., 1)` | улучшения, сложности, узлы древа; цвет рамки — смысл карточки |
| Тумблер | `ui/widgets/toggle_switch.gd` | вместо чекбоксов; включённый — золотой с галочкой |
| Сегменты | `ui/widgets/segmented.gd` | вкладки и выбор из 2–4 вариантов; выбранный — золотая «таблетка» |
| Ползунок | тема `HSlider` | золотая заливка, кремовый бегунок, значение справа цветом `YOLK` |
| Бейдж | `Design.chip(text, color)` | сложность, DEV, рекорд: заливка 16%, рамка 70% |
| Полоса | `Design.draw_bar()` | стамина, HP, загрузка: «таблетка» с бликом, «призрак» для потерянного HP |
| Баннер | `ui/captions.gd` | крупный текст по центру, появляется с пружиной |
| Сенсорные кнопки | `ui/touch_controls.gd` | круглые, полупрозрачные (настраивается), крупные иконки; стамина — кольцом вокруг кнопки спринта |

## Иконки

[`scripts/ui/icons.gd`](../scripts/ui/icons.gd) — процедурные, в сетке 24×24.

- **Сюжетные** (медведь, вилка, таблетка, яичница, атаки, сердце, чешуйка) — цветные «игрушки».
- **Служебные** (пауза, шестерёнка, назад, замок, галочка, молния, `</>`) — монохромные,
  штрих 2.5, скругления.

## Звук интерфейса

Звуки тоже часть языка, все синтезированы: `ui_move` (фокус), `ui_select` (нажатие),
`ui_toggle` (тумблер и сегмент), `ui_back` (назад), `ui_error` (нельзя, подтверди).
Мелодичные звуки играют без случайного сдвига высоты.

## Раскладка на разных экранах

- Игровое поле — всегда 1280×720. На широких экранах телефонов (19.5:9, 20:9) по бокам виден стол.
- Игровые панели прижаты к краям экрана и учитывают вырез камеры (safe area).
- Масштаб интерфейса (90–130%) меняет экраны меню, но не игровые панели.
- На сенсорном экране полоса HP яичницы переезжает наверх: внизу кнопки.
- Панели над полем становятся полупрозрачными, когда под ними ползёт змея.
