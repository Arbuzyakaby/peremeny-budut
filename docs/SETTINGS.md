# Настройки

Все настройки описаны одной таблицей `SCHEMA` в [`core/settings.gd`](../scripts/core/settings.gd).
По ней же строится экран настроек, проверяются значения из файла и сбрасываются умолчания.

## Строка схемы

```gdscript
{"key": "ui_scale", "tab": "screen", "kind": Kind.ENUM, "default": 2, "mobile": 3,
	"options": ["80%", "90%", "100%", "115%", "130%"], "label": "Масштаб интерфейса"}
```

| Поле | Смысл |
|---|---|
| `key` | ключ в `user://settings.cfg` и в коде (`Settings.flag/num/choice(key)`) |
| `tab` | вкладка: `sound`, `screen`, `game`, `controls`, `access`; `""` — скрытая (режим разработчика) |
| `kind` | `BOOL` — тумблер, `FLOAT` — крутилка (вкладка «Звук») или фейдер, `ENUM` — галетник |
| `default` / `mobile` | умолчание на ПК / на телефоне |
| `min`, `max`, `step` | диапазон числа (по умолчанию 0..1, шаг 0.05) |
| `options` | подписи положений галетника |
| `only` | `"mobile"` или `"desktop"` — строка видна только там |

Испорченный файл не ломает игру: `sanitize()` приводит каждое значение к типу и диапазону.

## Формат файла

В секции `[meta]` хранится `format`. Версия 2 (v7.2): у масштаба интерфейса появилось положение 80%,
индексы сдвинулись на единицу. Файл старого формата читается с поправкой: сохранённые 100% остаются 100%.
Добавляя положение в начало или середину существующего галетника, повышай `FORMAT` и добавляй миграцию
в `load_from_disk()`.

## Экран настроек (v7.2)

[`ui/screens/settings_screen.gd`](../scripts/ui/screens/settings_screen.gd) — компактный пульт:

- **шапка** — заголовок и латунная табличка с версией (7 нажатий — режим разработчика);
- **клавиши-вкладки** на всю ширину;
- **приборная ниша** — строки двумя колонками (колонка 380 px), заполняются сверху вниз, между строками —
  гравированные риски; значения крутилок и фейдеров — в окошках-счётчиках моноширинными цифрами;
- **подвал** — «Сброс настроек» (двойное нажатие), «Сброс рекордов» (под откидной крышкой) и «Готово».

Самая длинная вкладка (9 строк) помещается на экране 1280×720 без прокрутки; это проверяет тест
`test_settings_fit_without_scroll`. Если строк станет больше — прокрутка включится сама.

## Масштаб интерфейса

80 / 90 / 100 / 115 / 130%. По умолчанию 100% на ПК и 115% на телефоне. Меняет экраны меню и субтитры,
но не табло поверх поля.

## Как добавить настройку

1. Строка в `SCHEMA` на нужной вкладке.
2. Если она должна применяться сразу — ветка в `Settings.set_value()` или в `Hud.apply_setting()`.
3. Читать в коде через `Settings.flag/num/choice`.
4. Тест в `tests/unit/test_settings.gd`.
